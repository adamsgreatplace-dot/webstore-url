Privacy Policy for Skill Training Bars

Last updated: September 7, 2026

Skill Training Bars is a Chrome extension that adds custom skill-training progress bars and controls to D&D Beyond character sheets.

Information We Collect

Skill Training Bars does not collect, transmit, sell, or share personal information.

Information Read From D&D Beyond

When the user activates the extension on a D&D Beyond character sheet, the extension may read limited information visible on that page, such as skill names, displayed proficiency status, skill modifiers, and character level. This information is used only to provide the extension's functionality.

This information is processed locally in the user's browser and is not transmitted to the developer or to any external server.

Local Storage

The extension uses Chrome extension storage to save information needed for its features, including:

  • Skill-training XP and progression
  • Training history
  • Character-specific extension settings
  • Optional character-level overrides

This information remains in the user's browser unless the user removes or resets it.

Tracking, Analytics, and Advertising

Skill Training Bars does not use analytics, advertising, behavioral tracking, cookies, or third-party tracking technologies.

Remote Code and External Servers

Skill Training Bars does not execute remote code and does not require an external server to provide its core functionality.

Data Sharing

The extension does not sell, rent, transfer, or share user data with third parties.

Data Security

Because extension data is stored locally through Chrome's extension storage, users remain in control of their saved training information through their browser and extension installation.

Changes to This Policy

If the extension's data practices change in a future release, this privacy policy will be updated to describe those changes before they are introduced.

Contact

For privacy questions about Skill Training Bars, contact the developer through the support contact information provided on the Chrome Web Store listing.

Skill Training Bars is an independent fan-made extension and is not affiliated with or endorsed by D&D Beyond, Wizards of the Coast, or Hasbro.
